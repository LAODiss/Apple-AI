## 2. AnyGo 虚拟定位软件 (macOS 专版)
AnyGo 是一款强大的苹果设备位置模拟工具，此分享版本专供苹果 Mac 电脑使用。

> **⚠️ 安装警告**
> 此软件为 **Mac 电脑版**，请勿在手机或 Windows 电脑上安装。Windows 平台虽有同名软件，但必须前往官网下载并付费使用。

### 核心用途
* **虚拟定位：** 更改设备全局 GPS 定位（支持微信朋友圈定位变更）。
* **地图解锁：** 查看并使用满血版 Apple Maps。
* **功能开通：** 突破地域限制，开通 Apple Watch 血氧检测等被锁区功能。
